File examples

Sample files for UNICEDE/2.

For the XYZ Insurance Company, the Homeowner values insured for wind and fire (in ones) in Rhode Island may be:

County Name # of Risks Sums Insured

RHODE ISLAND 221. 67490000.Bristol 65. 20500000.Kent 72. 242500000.Newport 84. 22740000.

The portion of the BODY containing this data would then look like this (assuming the Data Units is coded as ones):

01-44000, PWF, PHO, BCT, 221, 67490000, 0, 0, 0, Rhode Island01-44001, PWF, PHO, BCT, 65, 20500000, 0, 0, 0, Bristol01-44003, PWF, PHO, BCT, 72, 24250000, 0, 0, 0, Kent01-44005, PWF, PHO, BCT, 84, 22740000, 0, 0, 0, Newport

t - For countries other than the United States and Canada, Subarea Name is the eleventh field in the body of the file; field 10 is an unused placeholder.

Note:

No premium or average deductible values are included in this sample. Zeros are used as placeholders when this information is not available.
