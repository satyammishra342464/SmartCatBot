Touchstone writes validation errors to the import log file. To view the validation error table, log in to the Client Portal, navigate to the Developer Zone, click the Touchstone Databases link (under "Database Documentation"), and then search for "tValidationError Table". The Description field for the ValidationErrorCode column lists the code that represents the validation error.
