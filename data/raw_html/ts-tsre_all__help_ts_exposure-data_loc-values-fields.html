Location values fields

Validation rules for fields related to the values associated with a location.

Select an exposure view, a contract in the contract list, the Contract Details pane, and then the location.

Field Description Validation rules Default value
Display Currency Currency for the display of financial values.

To view supported currency codes, log in to the Developer Zone on the Client Portal. Then navigate to the Touchstone area, click the Touchstone Databases link (under Database Documentation), and then search for "tCurrency Table. The Description field for the Currency Code column lists the ISO 3-character code for each currency.
  • Read-only
Total Replacement Value Total replacement value (all coverages combined) of this location.
  • Must be a numeric value between 0 and 999999999999999, inclusive.
  • Not applicable for workers' compensation locations.
Replacement Value Building Total replacement value of all the buildings that this location record covers.

Enter the actual value. Alternatively, enter 0 if the building is not covered.

Note the following special cases:

  • For the Great Britain and Germany Inland Flood models, if the floor of interest is not 0, this field represents the replacement value of the floor of interest only and not of the whole building.
  • For the Europe Extratropical Cyclone model, if the country is Norway (8), Sweden (9), or Finland (89), the occupancy code is 375 - Forestry, and you do not provide a building replacement value, Touchstone uses the gross area value in conjunction with the per-hectare forestry unit price values to determine the replacement value.
  • For workers' compensation policies, enter 0.
  • For the U.S. Hurricane Plate Glass Module, enter the total replacement value of all the glass in the building.
  • Defaults to a value in the Touchstone user interface.
  • Must be a numeric value between 0 and 999999999999999, inclusive.
  • Not applicable for workers' compensation locations.
0
Replacement Value Other Total replacement value of all appurtenant structures that this location record covers, such as outbuildings, sheds, gazebos, etc.

Enter the actual value or the insurance-to-value assumption as a decimal greater than or equal to 0 and less than or equal to 1. For example, enter 0.12 for 12%. Alternatively, enter 0 if other structures are not covered.

Touchstone does not support this field for workers' compensation policies, offshore platform policies, and the U.S. Hurricane Plate Glass Module. Enter 0.
  • Defaults to a value in the Touchstone user interface.
  • Must be a numeric value between 0 and 999999999999999, inclusive.
  • Not applicable for workers' compensation locations.
 0
Replacement Value Content Replacement value of contents that this location record covers.

Enter the actual value or the insurance-to-value assumption as a decimal greater than or equal to 0 and less than or equal to 1. For example, enter 0.12 for 12%. Alternatively, enter 0 if contents are not covered.

Note the following special cases:

  • For the Great Britain and Germany Inland Flood models, if the floor of interest is not 0, this field represents the replacement value of the contents in the floor of interest only and not of the contents in the rest of the building.
  • Touchstone does not support this field for workers' compensation policies, offshore platform policies, and the U.S. Hurricane Plate Glass Module. Enter 0.
  • Defaults to a value in the Touchstone user interface.
  • Must be a numeric value between 0 and 999999999999999, inclusive.
  • Not applicable for workers' compensation locations.
0
Replacement Value Time Yearly cost for all time element coverage for the risks that this location record covers.

Enter the actual value. Alternatively, enter 0 if time element is not covered. The value should correspond to the time indicated in the Replacement Value Days Covered field.

For example, if the per diem business interruption value is $10,000, enter 10,000 in the Replacement Value Time field and 1 in the Replacement Value Days Covered field. Alternatively, enter the yearly business interruption value 3650000 in this field and 365 in the Replacement Value Days Covered field. Both entries will produce identical results.

Touchstone does not support this field for workers' compensation policies, offshore platform policies, and the U.S. Hurricane Plate Glass Module. Therefore, enter 0.
  • Defaults to a value in the Touchstone user interface.
  • Must be a numeric value between 0 and 999999999999999, inclusive.
  • Not applicable for workers' compensation locations.
 0
Replacement Value Days Covered Number of days for which the replacement value time is in effect.

For example, if the replacement value time is per diem, enter 1. If the replacement value time is an annual total, enter 365.

Touchstone divides the replacement value time by the replacement value days covered. Consequently, you can select any number between 1 and 365, inclusive, that generates the best estimate of a per diem payout.

Touchstone does not support this field for offshore platform policies. Therefore, enter 0.
  • Required if you are creating a new record or editing an existing record.
  • Defaults to a value in the Touchstone user interface.
  • Must be a numeric value between 1 and 365, inclusive.
  • Not applicable for workers' compensation locations.
365
Number of Employees Number of covered employees at this location.

Enter 0 if you want to use the annual payroll and average annual wage instead of this field.

For aggregate Japan Personal Accident data, you should always supply a value for this field.
  • Required if you are creating a new record or editing an existing record for a location in Japan (i.e., for locations with a country code of JP).
  • Required if annual payroll is null.
  • Must be a numeric value between 1 and 999999999, inclusive.
  • Only applicable for workers' compensation locations.
 NULL
Annual Payroll Total annual payroll for all covered employees at this location.

If you provide the number of employees, enter 0 for this field.
  • Required if number of employees is null.
  • Must be a numeric value between 1 and 999999999, inclusive.
  • Only applicable for workers' compensation locations.
NULL
Average Annual Wage Average wage for all covered employees at this location.

The Touchstone default value for this field is the state average.

To use default values when importing data, leave this field empty in the *.csv import file.

During installation you can upgrade to the latest AIR default values when you upgrade the AIRExposure database. If you do not upgrade to the latest AIR default values, the values in AIRExposure remain consistent with the vintage of the database.
  • Optional
  • To use a default workers' compensation value for this field in the Touchstone user interface, you can either not enter a value in the field or you can delete an existing value for the field. If you leave the field blank, Touchstone uses the loss defaults specified in the Wages and Benefits section of the Administration Console.
  • Must be a numeric value between 1 and 999999999, inclusive.
  • Only applicable for workers' compensation locations.
Default
Percent Day Shift Percent of employees on premises at this location during the day shift, that is, during normal working hours (9 a.m. - 4:59 p.m.).

For locations in the United States (i.e., for locations with a country code of US), enter the percentage as a decimal greater than or equal to 0 and less than or equal to 1. For example, enter 0.12 for 12%.

Touchstone assumes that this percentage of employees will be at this location for eight hours per day.

For locations in Japan (i.e., for locations with a country code of JP), enter the percentage as a number greater than or equal to 0 and less than or equal to 100.

To use default values when importing data, leave this field empty in the *.csv import file.

During installation you can upgrade to the latest AIR default values when you upgrade to the latest AIRExposure database. If you do not upgrade to the latest AIR default values, the values in AIRExposure remain consistent with the vintage of the database.
  • Optional
  • To use a default workers' compensation value for this field in the Touchstone user interface, you can either not enter a value in the field or you can delete an existing value for the field. If you leave the field blank, Touchstone uses the loss defaults specified in the Wages and Benefits section of the Administration Console.
  • For locations in the United States (i.e., for locations with a country code of US), must be a numeric value between 0.00 and 1.00, inclusive.
  • For locations in Japan (i.e., for locations with a country code of JP), must be a numeric value between 0.00 and 100.00, inclusive.
  • Only applicable for workers' compensation locations.
Default
Percent Evening Shift Percent of employees on premises at this location during the evening shift, that is, during typical commute times (7 a.m. - 8:59 a.m., 5 p.m. - 6:59 p.m.).

Enter the percentage as a decimal greater than or equal to 0 and less than or equal to 1. For example, enter 0.12 for 12%.

Touchstone assumes that this percentage of employees will be at this location for four hours per day.

Touchstone ignores this field for the Japan Personal Accident model.

To use default values when importing data, leave this field empty in the *.csv import file.
