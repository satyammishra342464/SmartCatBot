Contract list

Validation rules for fields related to contracts.

Project Data > Exposure Views > {Select an Exposure View} > Contract List

Note: Touchstone does not support single-day contracts.
Field Description Validation Rules Default Value
Contract ID Unique, required, user-defined contract identifier.
  • Required if you are creating a new record or editing an existing record.
  • Must be unique.
  • Cannot begin with a space or contain commas or semicolons.
  • Can contain up to 100 characters.
Contract Type One of the following contract types:
  • Primary Property
  • Facultative Property
  • Primary Workers' Compensation
  • Facultative Workers' Compensatio
 Defaults to a value in the Touchstone user interface. Primary Property
Exposure Set Unique identifier for the exposure set to which this contract belongs.. Read-only
Insured Name Name of the insured party.
  • Optional.
  • Must be unique for the book.
  • Can contain up to 60 characters.
Producer Name Name of the producer.
  • Optional.
  • Can contain up to 60 characters.
Underwriter Name of the underwriter.
  • Optional.
  • Can contain up to 60 characters.
Branch Name of the branch.
  • Optional.
  • Can contain up to 60 characters.
ID of Expiring Contract ID of the expiring contract.
  • Optional.
  • Can contain up to 100 characters.
Terms Currency

Base currency for this contract

For analysis at the contract level, Touchstone converts all locations to this base currency.

Refer to the list of valid currency codes.

 Defaults to a value in the Touchstone user interface. US Dollar (USD)
Currency Exchange Rate Currency exchange rate. Read-only.
Inception Date

Date of the first day on which coverage is effective.

When importing data, use one of the following formats and select this format on the Options tab of ImportExpress:

  • MM/DD/YYYY
  • DD/MM/YYYY
  • YYYYMMDD
  • YYYY-MM-DD
  • Required if you are creating a new record or editing an existing record
  • Defaults to a value in the Touchstone user interface.
  • Date format is specific to locale of end user.
  • Must be less than the expiration date.
For inception and expiration dates, and other in-force dates, you must specify a date value between 01/01/1970 and 12/31/2038, inclusive, for dates based on U.S. regional settings. If you are not using U.S. regional settings, use a date value other than 01/01/1970, such as 01/01/1990.		 1/1/[current year]
Expiration Date

Date of the last day on which coverage is effective.

When importing data, use one of the following formats and select this format on the Options tab of ImportExpress:

  • MM/DD/YYYY
  • DD/MM/YYYY
  • YYYYMMDD
  • YYYY-MM-DD
  • Required if you are creating a new record or editing an existing record.
  • Defaults to a value in the Touchstone user interface.
  • Date format is specific to locale of end user.
  • Must be greater than the inception date.
For inception and expiration dates, and other in-force dates, you must specify a date value between 01/01/1970 and 12/31/2038, inclusive, for dates based on U.S. regional settings. If you are not using U.S. regional settings, use a date value other than 01/01/1970, such as 01/01/1990.		 12/31/[current year]
Status

One of the following contract submission statuses where the letters represent the SubmitStatusCode in the database reference:

  • Authorized (A)
  • Bound (B)
  • Cancelled (C)
  • Expired (E)
  • Quoted (Q)
  • Rejected (R)
  • Renewal (RN)
  • Submitted (S)
 Defaults to a value in the Touchstoneuser interface. Submitted
Perils

Perils insured under this contract.

Refer to the list of valid peril codes.

Note: To specify multiple perils in a single entry within an import file, separate the corresponding peril codes with a plus (+) symbol, for example: PWH+PES.
 Defaults to a value in the Touchstone user interface. All perils (PAL)
Policy Form User-defined policy form assigned to this contract.
  • Defaults to a value in the Touchstone user interface.
  • Can contain up to 60 characters.
 Unknown
Line of Business User-specified line of business.
  • Defaults to a value in the Touchstone user interface.
  • Lines of business should be unique between property and workers' compensation, if you need to see data separately for property and workers' compensation.
  • Can contain up to 60 characters.
 Unknown
Location Count Number of locations in this contract. Read-only
Layer Count Number of layers in this contract. Read-only
Layer Level Reinsurance Count Number of reinsurance treaties in the layer(s) in this contract. Read-only
Location Level Reinsurance Count Number of reinsurance treaties associated with the location(s) that this contract covers. Read-only
Step Function One of the following values to Indicate whether this contract includes a step function:
  • Yes
  • No
 Read-only
Total Replacement Value Total replacement value for each contract.
  • Defaults to a value in the Touchstone user interface, provided that an exposure summary has been generated for the exposure view.
  • Value changes if Display Currency settings change for the project.
TRV Currency The currency used to calculate the TRV.
  • Defaults to the currency selected when the exposure view was created.
  • Touchstone dynamically converts all location TRVs using the exposure view currency and conversion rate; it does not store these values in the database.
